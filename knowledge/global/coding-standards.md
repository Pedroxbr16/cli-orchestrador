# Convenções de desenvolvimento

Use JavaScript com ES Modules e async/await. Preserve a separação entre comandos, configuração, agents, permissões e execução de processos.

Valide entradas antes de iniciar operações. Mantenha testes para comportamentos importantes, erros e limites de permissão.

# Git e permissões

Git remoto fica desabilitado por padrão. Force push, push para main/develop e exclusão de referências remotas exigem liberação explícita na política.

Prompts e documentos de conhecimento não substituem o Git Guard. Engines sem integração segura permanecem bloqueados.
